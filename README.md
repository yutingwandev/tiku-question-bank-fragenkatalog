## 中文

### 项目介绍

这是一个**在线刷题网页**，打开链接就能用，不用安装任何东西。

- **4000 多道题**，分成 10 个科目：Python、NumPy、Pandas、Matplotlib、Jupyter 数据分析练习、SQL、数据分析方法和模型、数据分析指标与指标体系、咨询面试框架及习题、Case 新手大礼包
  （Pandas 暂时还没有题目）
- 题型有：选择、填空、判断、简答、编程、程序填空、习题、笔记
- 每道题都有**中文、英文、德文**三种语言，可以随时切换
- 很多题带有「💬 大白话」解释，用简单的话讲清楚题目在问什么
- **自动判对错**，并且**记住你做过的题和错题**
- 可以在**电脑和手机之间同步**做题记录
- 可以**嵌进 Notion** 里直接使用

### 使用方法

| 你想做什么 | 怎么做 |
|---|---|
| 换科目 | 点最上面的灰色科目栏 |
| 换题库 | 点科目下面的题库按钮 |
| 换题型 | 点「选择 / 填空 / 判断……」标签 |
| 只看某一章 | 用「全部章节」下拉菜单 |
| 换语言 | 点「中 / EN / DE」按钮，可以同时开好几种 |
| 做选择题、判断题 | 点一个选项，马上判对错 |
| 做填空题 | 在横线上写答案，再点「答案」，答对的横线会变绿 |
| 做简答题、编程题 | 在框里写答案，点「答案」对照，再自己点 **✓ 会了** 或 **✗ 错了** |
| 看答案 | 点题目下面的「答案」；点「全部答案」一次全打开 |
| 只看错题 | 用「全部题目」下拉菜单，选「错题本」 |
| 看进度 | 看进度条：已做多少题、对多少题、错多少题 |
| 清空写过的答案 | 点「清空」（不会删除 ✓ ✗ 记录） |

**开启同步（电脑和手机各做一次）**

1. 点进度条右边的小字「仅存本机 · 点这里开启同步」
2. 点面板里的链接，登录 GitHub，拉到最下面点绿色按钮 **Generate token**
3. 复制出现的那串 `ghp_…` 字，贴回题库页面，点「连接」
4. 看到「☁ 已同步」就好了

> 这串字只存在你自己的设备上，只能读写你 GitHub 里一个私密的 Gist（`tiku-progress.json`），做题记录就存在那里。不要把它发给别人。

**放进 Notion**

在 Notion 页面里输入 `/embed`，贴上上面的在线链接，把框拉大一点就可以了。

### 使用顺序

1. **打开**在线链接
2. **开启同步**（第一次用的时候做一次，每台设备各一次）
3. **选科目**
4. **选题库**
5. **选题型**，需要的话再选章节
6. **选语言**
7. **做题**
8. **对答案**：选择题、判断题点完就判；其它题点「答案」
9. **标记**：没有自动判的题，自己点 ✓ 或 ✗
10. **复习错题**：下拉菜单选「错题本」，把错题再做一遍，做对了点 ✓

## English

### About

An **online practice page** for question banks. Just open the link, nothing to install.

- **4,000+ questions** in 10 subjects: Python, NumPy, Pandas, Matplotlib, Jupyter data-analysis exercises, SQL, data-analysis methods & models, metrics & metric systems, consulting case frameworks & exercises, and a case-interview starter pack
  (Pandas has no questions yet)
- Question types: multiple choice, fill-in-the-blank, true/false, short answer, coding, code completion, exercises, notes
- Every question is available in **Chinese, English and German**, switchable at any time
- Many questions come with a "💬 plain-language" hint (in Chinese) that explains what is being asked
- **Automatic checking**, and the page **remembers what you have done and what you got wrong**
- Your progress can **sync between computer and phone**
- Can be **embedded in Notion**

### How to use

| What you want | How |
|---|---|
| Change subject | Click the grey subject bar at the top |
| Change question bank | Click a bank button below the subjects |
| Change question type | Click the "Choice / Fill-in / True/False …" tabs |
| Show one chapter only | Use the "All chapters" drop-down |
| Change language | Click "中 / EN / DE" — several can be on at once |
| Multiple choice, true/false | Click an option; it is checked immediately |
| Fill-in-the-blank | Type on the line, then click "Answer"; correct blanks turn green |
| Short answer, coding | Write in the box, click "Answer" to compare, then click **✓ Got it** or **✗ Wrong** yourself |
| See the answer | Click "Answer" under the question; "All" opens every answer |
| Show only mistakes | In the "All" filter drop-down, choose "Wrong" |
| See progress | The progress bar shows done / right / wrong |
| Clear typed answers | Click "Clear" (your ✓ ✗ record is kept) |

**Turn on sync (once on each device: computer and phone)**

1. Click the small text to the right of the progress bar ("仅存本机 · 点这里开启同步" = "this device only · click to enable sync")
2. Click the link in the panel, sign in to GitHub, scroll down and click the green **Generate token** button
3. Copy the `ghp_…` string, paste it into the page and click "连接" (Connect)
4. When you see "☁ 已同步" (synced), you are done

> The token stays only on your own device and can only read and write one secret Gist in your GitHub account (`tiku-progress.json`), where your progress is stored. Never share it.

**Put it in Notion**

In a Notion page type `/embed`, paste the online link above and make the box larger.

### Order of use

1. **Open** the online link
2. **Turn on sync** (once, on each device)
3. **Choose a subject**
4. **Choose a question bank**
5. **Choose a question type**, and a chapter if you like
6. **Choose languages**
7. **Answer the questions**
8. **Check**: choice and true/false are checked on click; for the rest click "Answer"
9. **Mark**: for questions that are not checked automatically, click ✓ or ✗
10. **Review mistakes**: choose "Wrong" in the filter, redo them, click ✓ when you get one right

## Deutsch

### Projektbeschreibung

Eine **Online-Übungsseite** für Fragenkataloge. Einfach den Link öffnen, nichts installieren.

- **Über 4.000 Aufgaben** in 10 Fächern: Python, NumPy, Pandas, Matplotlib, Jupyter-Datenanalyse-Übungen, SQL, Methoden und Modelle der Datenanalyse, Kennzahlen und Kennzahlensysteme, Frameworks und Übungen für Consulting-Cases sowie ein Case-Interview-Einsteigerpaket
  (Pandas enthält noch keine Aufgaben)
- Aufgabentypen: Auswahl, Lückentext, Richtig/Falsch, Kurzfragen, Programmieren, Code ergänzen, Übungen, Notizen
- Jede Aufgabe gibt es auf **Chinesisch, Englisch und Deutsch**, jederzeit umschaltbar
- Viele Aufgaben haben eine „💬 einfach erklärt“-Hilfe (auf Chinesisch), die erklärt, worum es geht
- **Automatische Kontrolle** – die Seite **merkt sich, was du gemacht und was du falsch hattest**
- Der Fortschritt kann **zwischen Computer und Handy synchronisiert** werden
- Lässt sich **in Notion einbetten**

### Bedienung

| Was du möchtest | So geht's |
|---|---|
| Fach wechseln | Oben auf die graue Fächerleiste klicken |
| Fragenkatalog wechseln | Auf einen Katalog-Button unter den Fächern klicken |
| Aufgabentyp wechseln | Auf die Reiter „Auswahl / Lückentext / Richtig/Falsch …“ klicken |
| Nur ein Kapitel zeigen | Das Menü „Alle Kapitel“ benutzen |
| Sprache wechseln | Auf „中 / EN / DE“ klicken – mehrere gleichzeitig möglich |
| Auswahl, Richtig/Falsch | Eine Option anklicken – sie wird sofort geprüft |
| Lückentext | Antwort auf die Linie schreiben, dann „Lösung“ klicken; richtige Lücken werden grün |
| Kurzfragen, Programmieren | Ins Feld schreiben, „Lösung“ zum Vergleichen klicken, dann selbst **✓ Got it** oder **✗ Wrong** klicken |
| Lösung ansehen | Unter der Aufgabe auf „Lösung“ klicken; „Alle“ öffnet alle Lösungen |
| Nur Fehler zeigen | Im Filter „All“ den Eintrag „Wrong“ (错题本) wählen |
| Fortschritt sehen | Der Fortschrittsbalken zeigt erledigt / richtig / falsch |
| Eingaben löschen | „Leeren“ klicken (die ✓-✗-Einträge bleiben erhalten) |

**Synchronisierung einschalten (einmal pro Gerät: Computer und Handy)**

1. Auf den kleinen Text rechts neben dem Fortschrittsbalken klicken („仅存本机 · 点这里开启同步“ = „nur auf diesem Gerät · zum Synchronisieren klicken“)
2. Im Feld auf den Link klicken, bei GitHub anmelden, nach unten scrollen und den grünen Button **Generate token** klicken
3. Die Zeichenfolge `ghp_…` kopieren, in die Seite einfügen und „连接“ (Verbinden) klicken
4. Steht dort „☁ 已同步“ (synchronisiert), ist alles fertig

> Der Token bleibt nur auf deinem eigenen Gerät und kann nur einen geheimen Gist in deinem GitHub-Konto (`tiku-progress.json`) lesen und schreiben, in dem dein Fortschritt gespeichert wird. Gib ihn niemals weiter.

**In Notion einbinden**

In einer Notion-Seite `/embed` eingeben, den Online-Link von oben einfügen und das Feld größer ziehen.

### Reihenfolge

1. Den Online-Link **öffnen**
2. **Synchronisierung einschalten** (einmal pro Gerät)
3. **Fach wählen**
4. **Fragenkatalog wählen**
5. **Aufgabentyp wählen**, bei Bedarf auch ein Kapitel
6. **Sprachen wählen**
7. **Aufgaben lösen**
8. **Kontrollieren**: Auswahl und Richtig/Falsch werden beim Klicken geprüft, sonst „Lösung“ klicken
9. **Markieren**: Aufgaben ohne automatische Kontrolle selbst mit ✓ oder ✗ markieren
10. **Fehler wiederholen**: Im Filter „Wrong“ wählen, die Aufgaben noch einmal lösen und bei Erfolg ✓ klicken
